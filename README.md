# InventarisKu

InventarisKu adalah aplikasi inventaris barang berbasis React Native yang dibuat menggunakan Expo. Aplikasi ini membantu pengguna mencatat dan mengelola stok barang secara sederhana.

## Fitur Aplikasi

1. **Beranda** — menampilkan total jenis barang dan total stok.
2. **Daftar Barang** — menampilkan daftar barang beserta jumlah stoknya.
3. **Tambah Barang** — menambahkan barang baru dengan nama dan jumlah stok.
4. **Hapus Barang** — menghapus barang dari daftar.
5. **Penyimpanan Lokal** — menyimpan data barang menggunakan AsyncStorage agar data dapat dimuat kembali saat aplikasi dibuka.

## Teknologi yang Digunakan

- JavaScript
- React Native
- Expo SDK 54
- AsyncStorage

## Cara Menjalankan

1. Buka proyek InventarisKu di Expo Snack.
2. Pastikan dependensi yang dibutuhkan tersedia.
3. Jalankan aplikasi melalui preview Snack atau Expo Go yang kompatibel dengan SDK proyek.
4. Gunakan menu Beranda, Daftar Barang, dan Tambah Barang untuk mengelola inventaris.

## Struktur File

- `App.js` — kode utama aplikasi.
- `package.json` — konfigurasi proyek dan dependensi.
- `README.md` — dokumentasi proyek.

## Tujuan

Proyek ini dibuat sebagai tugas pembelajaran pengembangan aplikasi mobile dengan React Native.
